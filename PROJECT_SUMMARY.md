# Project Summary - TeamEnergy Bill Management Frontend

## Overview
This project is a modern enterprise frontend for bill processing and approvals. It is built with React, Vite, and Tailwind CSS and is designed for a clean finance workflow.

## Included flow
- Login
- Dashboard
- Bill Logging
- Bill History
- Bill Details
- Settings
- Organization Accounts (Admin only)

## Current features
- Role-based mock login
- Dynamic sidebar navigation
- Dashboard summary cards
- Bill submission form with validation
- Document upload support
- Searchable bill history
- Detailed bill timeline and status view
- Settings page with multiple sections
- Admin-only organization account management
- Responsive enterprise UI

## Tech stack
- React 19
- Vite
- Tailwind CSS
- React Router
- Zustand
- Axios
- React Hook Form

## Notes
The app currently uses realistic mock data and mock authentication, while the service layer is structured for easier backend integration later.
