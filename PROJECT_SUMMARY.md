# Project Summary

TeamEnergy is an electricity bill management frontend for tracking energy usage, uploading bills, and monitoring reduction goals.

## Included flow
- Login
- Dashboard
- Upload electricity bill
- OCR validation
- Bill history
- Approval review
- Settings
- Admin account management

## Current features
- OCR-based bill extraction
- Energy reduction goal tracking
- Consumption and billing dashboard
- Searchable electricity bill history
- Role-based access control
- Responsive layout for desktop and mobile

## Unique features by user
- Admin: manages users and organization accounts
- Approver: reviews and validates bill approvals
- Staff: uploads and corrects electricity bills
- Viewer: monitors dashboard and history only

## Tech stack
- React 19
- Vite
- Tailwind CSS
- React Router
- Zustand
- React Hook Form

## Commands
```bash
npm install
npm run dev
npm run build
```
